## 🔥 Pump Detection

### **4 Tespit Türü:**

1. **Volume Spike**
   - 3-10x normal hacim
   - Aniden artan aktivite

2. **Price Surge**
   - 5-15 dakikada %10-50+ artış
   - Momentum patlaması

3. **Volatility Spike**
   - ATR 2.5x+ artış
   - Anormal fiyat hareketleri

4. **Coordinated Buying**

## ⚠️ Önemli Notlar

### **Pump Trading Riskleri:**

1. **False Positives:**
   - Her pump sinyali gerçek değildir
   - Confirmation bekleyin
   - Multiple signals arayin

2. **Timing:**
   - Pump detection tespit eder, tahmin etmez
   - Alert geldiğinde pump başlamış olabilir
   - FOMO'ya kapılmayın

3. **Risk Management:**
   - Stop-loss kullanın
   - Position size küçük tutun
   - Kârda sat, zararı kes

4. **Market Conditions:**
   - Bear market: Daha az pump
   - Bull market: Daha fazla pump
   - High volatility: Daha fazla false positive

### **En İyi Uygulamalar:**

1. **Patience:**
   - İlk 1 saat veri biriktirin
   - Pump her zaman olmaz
   - Normal piyasa = sinyal yok

2. **Diversification:**
   - Tek coin'e focus etmeyin
   - 90+ coin'i izleyin
   - Fırsatları kaçırmayın

3. **Confirmation:**
   - Dashboard'da grafiği kontrol edin
   - Volume'u doğrulayın
   - Multiple timeframe analizi

4. **Learning:**
   - Alert history inceleyin
   - False positive oranını öğrenin
   - Pattern'leri tanıyın

- Single exchange kullanın

### **No data for some coins:**
- Exchange'de listelenmiyor olabilir
- Symbol adı yanlış olabilir
- `config/trading_pairs.py` kontrol edin
