ADIM 1: MEVCUT SİSTEMİ DURDUR
─────────────────────────────────────────
Eğer sistem çalışıyorsa:
→ Trading Engine penceresinde CTRL + C
→ Dashboard penceresini kapat
→ Tüm pencereleri kapat


ADIM 2: SİSTEMİ SIFIRLA (Opsiyonel - İlk Kez İçin)
─────────────────────────────────────────
Çift tıkla:
→ RESET_SYSTEM.bat

Bu şunları yapar:
✓ Tüm pozisyonları siler
✓ Bakiyeyi $10,000'a sıfırlar
✓ Log dosyalarını temizler
✓ Alert'leri siler


ADIM 3: SİSTEMİ BAŞLAT
─────────────────────────────────────────
Çift tıkla:
→ START_AUTO_TRADING_SIMPLE.bat

veya

PowerShell'de:
→ cd C:\Users\Botai\Desktop\Projeler\ClaudeCodeCoin
→ .\START_AUTO_TRADING_SIMPLE.bat


ADIM 4: DASHBOARD'U AÇ
─────────────────────────────────────────
Tarayıcıda:
→ http://localhost:8501

Görecekleriniz:
✓ Bakiye: $10,000
✓ Açık Pozisyonlar
✓ Pump Alertleri
✓ Canlı Grafikler


ADIM 5: BEKLEYİN & İZLEYİN
─────────────────────────────────────────
İlk sinyal: 5-30 dakika içinde
Trading Engine'de göreceksiniz:

🔍 SORUN GİDERME
═══════════════════════════════════════════════════════════════════════

PROBLEM: Dashboard açılmıyor
→ Port kullanımda mı kontrol et: netstat -ano | findstr :8501
→ Process'i öldür: taskkill /F /PID <PID>
→ Yeniden başlat: streamlit run dashboard.py

PROBLEM: Hiç sinyal gelmiyor
→ NORMAL! Pump sinyalleri zaman alabilir (5-60 dk)
→ Scanner çalışıyor mu? Log'lara bak
→ Ayarları gevşet: MIN_CONFIDENCE_TO_TRADE = 30.0

PROBLEM: Pozisyon açılmıyor
→ Fiyat verisi var mı? python CHECK_COLLECTORS.py
→ Database dolu mu? data_output/binance_data.db kontrol et
